TestFlow 测试设计工作台  版本 {version}
==========================================

一、启动
  1. 把压缩包完整解压到任意目录（路径可以有中文和空格，但不要直接在压缩包里双击运行）。
  2. 双击 start.bat。会弹出一个命令行窗口，几秒后浏览器自动打开 http://127.0.0.1:8010/
     端口被占用时会自动换到 8011、8012……，以窗口里显示的地址为准。
  3. 关闭命令行窗口即停止服务。

  不需要安装 Python，内置运行环境在 python\ 目录。

二、首次使用：配置大模型
  打开页面后点左下角“系统设置”→“大模型”，填写：
    - 接口地址：OpenAI 兼容接口，写到 /v1 为止，例如 https://api.openai.com/v1
    - API Key
    - 模型名称：例如 gpt-4o-mini、deepseek-chat、qwen-plus
  点“测试连接”确认可用后点“保存”。Bugzilla 地址和 API Key 也在“系统设置”里配置。

三、常用参数（在命令行里运行 start.bat 时追加）
  start.bat --port 9000          指定端口
  start.bat --host 0.0.0.0       允许局域网其它电脑访问（注意防火墙放行）
  start.bat --no-browser         不自动打开浏览器

四、数据与升级
  所有配置、测试设计历史、上传的 RAG 文档、在网页上改过的 Prompt 都保存在 data\ 目录。
  升级时解压新版本，把旧版本的 data\ 目录整个复制过去覆盖即可。
